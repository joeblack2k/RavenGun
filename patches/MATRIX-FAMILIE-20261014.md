**The Matrix / SBK LPT dongle family.** One page. Lane: licence/hardware emulation.

**Nothing here was run.** The bench is busy; this is static analysis and reading only. NAS read-only.

## The family in one paragraph

The Matrix (a.k.a. SBK) is a **2009 LPT dongle** — an old parallel-port key, shared by the whole
Adrenaline/Sarbakan Unity line. Both original DLLs (`matrix32.dll` 114688 md5 `6e75f453dca9380144620d80f467a0e6`,
`matrix64.dll` 93184 md5 `c86908ab10b1d9249c896e42b7618f67`) are byte-identical in every dump that has them.
Every game in the family loads it from `Game_Data/Plugins/` (or `Game_Data/Plugins/x86_64/` on 64-bit
IL2CPP) and asks the **same two or three questions** — the dongle count, a serial number, and
`Init_MatrixAPI`. **We already build the answer**: `matrix/src/` produces `matrix32.dll` and `matrix64.dll`
with the original's 113 export names, and returns `Init_MatrixAPI` → 0, `Dongle_Count` → 2 (the port argument
is ignored), `Dongle_ReadSerNr` → 69420, and `Encrypt`/`Decrypt` → 0 with the buffer untouched.
Rabbids Hollywood is measured working through it for 288 s with the game logging `**** DONGLE FOUND: 69420`.

## The single biggest unknown in this family

**Whether any Matrix check other than Rabbids Hollywood's is actually *fatal* — and specifically whether Drakons
Realm Keepers quits without a dongle.** Rabbids is the only game where the death was measured and explained
(`MatrixManager.Awake` → 30 s `WaitForSeconds` → `Application.Quit`). Rampage demonstrably shrugs, Tomb Raider
was blocked by its I/O board and never by the dongle, and Drakons is unknown. It matters because it decides
whether the drop-ins are *required* or merely *correct*: if only Rabbids enforces it, then four of the five
Matrix drop-ins are optional, one of them (Rampage) should probably be removed to honour "never enable anything
implicitly", and the family's real remaining work is **not** the emulation but (a) the Infinity Blade FX
ordinal fix and (b) a single decision per game. The cheap way to close it is one negative-control run each,
which is what every "proposed test" column above already asks for.

## Secondary, and independent of the above

**`matrix.def`'s ordinal layout is a latent break for any native PE title that imports from a static table.**
Infinity Blade FX is the instance we found; the class is "every non-Unity Matrix game". The ABI gate does not
catch it today because it checks names and `ret N`, not ordinals.

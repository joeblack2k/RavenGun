# Wiki drafts

Drafts of the RavenGun wiki pages (2026-10-13), kept in the repository because a GitHub wiki on a private repository needs a
paid plan. The top-level pages are the latest version; `concept/` is the earlier draft (the same as the never-pushed local
`ravengun.wiki` repository); `gereedschap/` holds the page checker (`wiki-check.py`). They describe the state of 2026-10-13
and are not kept up to date; `docs/` and `docs/compatibility.md` are current.

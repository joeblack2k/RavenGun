# RavenGun — takenlijst

Leidraad van de eigenaar (2026-10-10): alle games in de TeknoParrot-map werken zo goed mogelijk met onze lightgun, en er is één app (Qt, Engels, in de stijl van Dolphin) die alles regelt, ook in Steam Game Mode. Deze lijst wordt bijgewerkt na elke afgeronde stap. Status: [ ] open, [~] bezig, [x] klaar.

## Besluiten (2026-10-10)

- De engine (ravengund) blijft een achtergrondservice; de Qt-app start, stopt en bedient hem. De app is het enige wat de gebruiker ziet.
- De webpagina blijft alleen als afstandsbediening voor de telefoon; aan/uit in de app.
- Licentie: GPL-3.0-or-later (LICENSE). Daarmee mag code uit Dolphin (GPL-2.0-or-later) en OpenParrot (GPL-3.0) worden overgenomen, met bronvermelding. De DemulShooter-plugin (geen licentie) wordt niet meegeleverd; vervangen door een eigen plugin.
- RavenGun vervangt de TeknoParrot-UI voor de gebruiker (bibliotheek, opties, invoer, starten). De TeknoParrot-runtime (loaders en cores uit het abonnement van de eigenaar) blijft een afhankelijkheid, zoals een frontend een emulatorcore nodig heeft; de gebruiker opent TeknoParrotUi niet meer.
- App-teksten in het Engels; code-commentaar en interne docs blijven Nederlands.
- Eerste gebruik: inrichten in Desktop Mode met een wizard (rechten, Moves koppelen, kalibratie, gamemap toevoegen, toevoegen aan Steam); daarna werkt alles na een herstart ook in Game Mode via de fullscreen-modus van de app.

## Spoor A — Qt-app

- [x] A1 Architectuur en skelet: Qt 6 Widgets (gelijk aan de systeem-Qt 6.11 van SteamOS), hoofdvenster naar het voorbeeld van Dolphin (gamelijst/raster, werkbalk Play/Stop/Config/Controllers/Add Folder/Fullscreen), praat met de engine via de bestaande IPC-socket. Gebouwd in een container (scripts/build-app.sh, docs/build.md), kern zonder widgets voor A7, launcher-backends (teknoparrot-ui nu, direct later).
- [x] A2 Gamebibliotheek: "Add Folder" scant een map en herkent alle games (TeknoParrot-profielen, sjablonen op bestandsnaam, game-options.json, Unity-route, overige als Unconfigured), met iconen en status per game; "Set Up Game" maakt op verzoek het profiel (tp-add-game.py).
- [x] A3 Per game "Properties" (rechtsklik > Edit): opties uit packaging/game-options.json (bibliotheek = bron van waarheid, ProfileSync naar het profiel), Display, invoerroute, "memory card" (bekijken en lokaal wissen). Getest tegen de echte game-options.json: alle 37 games openen zonder Qt-waarschuwing en tonen al hun 564 opties (448 in Options, de rest onder Display of door de app geregeld; widgettest). Nieuw te bewerken formaten: ini_onoff, ini_yesno, tab_ini, space_ini, colon (opmaak blijft staan); rtdt_adjval, csv, xml, shell_arg, colon_text, ini_line_comment en base wine_prefix blijven alleen-lezen met reden. De invoerroute is per game te kiezen (alleen routes waarvoor een indeling of bord bestaat); de keuze staat als `[Input] Route` in het gebruikers-`game.ini` (`~/.local/share/ravengun/patches/<Game>/`), gaat voor het meegeleverde `patches/<Game>/game.ini` en wordt gelezen door de engine (bij elke start, zonder herstart) en door play-halo.sh (`scripts/gamesettings.py`). Spelersnotities zijn tweetalig (`Note` Nederlands voor web en engine, `NoteEN` Engels voor de app) met een `Status` per game (playable/parked), in `[Status]` van `game.ini`. Opties van games op de NAS blijven alleen-lezen zolang er geen lokale view is (beleid).

Sharp Shooter en Navigation Controller, Calibration), koppelwizard, hernoemen, speler kiezen (ook Navigation Controller), knipperen, verwijderen; muis als lightgun in de engine (IPC mice/set_mouse_gun). - [x] A9 Verpakking voor GitHub (2026-10-10, branch `worktree-agent-a69061f715ebd200d`; details in docs/build.md "Installatie-indeling" en "Release-artefact", stappen in docs/procedures.md):

  - Open: de echte installatie op deze machine overzetten (docs/procedures.md, "De echte installatie op deze machine overzetten"; orchestrator) en de eerste release op GitHub zetten (er is nog geen remote); proberen op een tweede, schone SteamOS-installatie (alleen op deze machine geprobeerd).
